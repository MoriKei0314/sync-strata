# Sync-Strata のインストール・更新・アンインストール

この文書の 1〜6 は Windows の手順です。Linux は最後の「Linux」の節を読んでください。

## Windows

Sync-Strata は、自分の PC の GPU で動くローカルの LLM のアプリです。会話の画面（dsh）とエンジンが同梱されています。

## 1. 要求スペック

| 種類 | 条件 |
|---|---|
| OS | Windows 10（1803 以降）か Windows 11、64 ビット |
| GPU | NVIDIA の RTX 20〜50 系・GTX 10 系・Tesla P100・Tesla V100・Titan V、AMD Radeon の RX 6000・7000・9000 系（単体の GPU。RX 7600M などのノート用も。試験的な機能）。対応する GPU の全部は [README](../README.ja.md) の表。GPU のメモリは 8 GB 以上（12 GB 以上を推奨）。GPU が何枚あっても使うのは 1 枚だけです（対応する GPU のうちメモリが一番多い GPU）。NVIDIA のドライバーは R580 以上（CUDA 13.0 が動くバージョン）。GTX 10 系・P100・V100・Titan V（CUDA 12 版）は 576.57 以上 |
| CPU | AVX2 が必要です |
| RAM | モデルで違います。Sync-XS は 24 GB 以下の PC 向け、Sync-S は 32 GB、Sync-M は 48 GB 以上の PC 向け（アプリが積んでいる RAM の量で選びます） |
| 空き容量 | アプリ 約 2 GB（更新の間は前のバージョンを 1 つ残すので、その分も）＋どのモデルにも必要な共通のコンポーネント 約 35 GB ＋ モデル（Sync-XS 約 24 GB・Sync-S 約 28 GB・Sync-M 約 35 GB）。モデルは速い SSD（NVMe）に |
| 管理者の権限・PC の Python や Node | 不要（全部アプリに含まれています） |
| ネットワーク | インストールのときは不要（zip の中に全部あります）。モデルをダウンロードするときと更新のときだけ必要 |

## 2. インストールする（初回・修復・別の PC、どれも同じ）

1. ダウンロードした zip を展開する（例: 展開先のフォルダー `SyncStrata-0.1.0-1115`）。フォルダーの名前に日本語が含まれない場所を推奨します。
2. 中の `setup.cmd` をダブルクリック。
   - すでにインストールされているコンポーネントを調べ、**足りない・古い・壊れたコンポーネントだけ**をインストールします。何度実行しても同じ結果になります。
   - 最後に、コンポーネントごとに「入れた／直した／飛ばした」を 1 行ずつ出します。
   - アプリは `%LOCALAPPDATA%\Programs\SyncStrata` にインストールされます。別の場所にするときは、コマンドプロンプトで
     `setup.cmd -AppDir <入れる場所>` のように。
3. デスクトップの **Sync-Strata** をダブルクリック。モデルがまだ無いときは、最初の画面にモデルをダウンロードする案内が出ます。

### モデルがもう手元にあるとき

計測キットなどでダウンロードしたモデル（`models\` の中に `sync-s-sb\` などがある並び）があれば、setup が探して見つけ、
**ダウンロードし直さずに**その場所を使います（展開した zip の隣、ドライブの直下から 2 段まで、ユーザーのフォルダーの中を探します）。
見つからないときや別の場所を使いたいときは `setup.cmd -ModelsDir <モデルのフォルダー>` のように指定してください。

## 3. 更新する

### アプリの画面から

設定（スタートの設定）の **更新** を開きます。

- **更新をチェックする** を押すと、いまのバージョンと新しいバージョン、置き換わるコンポーネントと大きさ、リリースの説明を出します。確認するだけで、何もダウンロードしません。押すまで確認しません。
- **閉じて更新する** を押して「はい」を選ぶと、Sync-Strata を閉じて更新し、終わると再起動します。ウィンドウ（Linux は端末。無ければ `SYNC_HOME/logs/update-<日時>.log`）に様子が出ます。会話とダウンロードは停止します。
- 閉じて更新できるのは **PC の画面から**だけです。スマホでは確認するだけです。
- 配布元に届かないときは、理由と、手動でインストールする方法（リリースの zip を置くフォルダー）を出します。

### スタートメニューから

スタートメニューの **Sync-Strata の更新**（インストール先の `update.cmd`）をダブルクリック。

- 新しいバージョンの一覧を見て、**変わったコンポーネントだけ**をダウンロードして置き換えます。
- **アプリが動いている間は置き換えません**。アプリの画面を「全て閉じる」で閉じてから実行してください。
- モデルと、設定・会話（`SYNC_HOME`）には触れません。
- 置き換える前のバージョンを 1 つ残します。新しいバージョンで困ったら、スタートメニューの **Sync-Strata を前の版に戻す**（`rollback.cmd`）。
- 更新の配布元は設定（`settings.json` の `update_feed`）で変更できます。手元のフォルダーや URL を指定するときは
  `update.cmd -Source <新しい版の feed のフォルダー>` のように。

## 4. アンインストールする

スタートメニューの **Sync-Strata を消す**（インストール先の `uninstall.cmd`）。

- アプリと、setup が作ったアイコンを削除します。
- モデルと、設定・会話（`SYNC_HOME`、既定 `%LOCALAPPDATA%\SyncStrata`）は、削除するかどうかを聞きます（既定は残す）。

## 5. 保存先

| 保存先 | 中身 | 更新のとき |
|---|---|---|
| アプリ（`%LOCALAPPDATA%\Programs\SyncStrata`） | アプリの枠・起動のツール・会話の画面・エンジン・Python・Node・dsh | 置き換える（前のバージョンを 1 つ残す） |
| モデル（`settings.json` の `models_dir`） | モデルのファイル | 触らない |
| 利用者のデータ（`SYNC_HOME`、既定 `%LOCALAPPDATA%\SyncStrata`） | `settings.json`・dsh の設定と会話（`dsh-home\`） | 触らない |

## 6. 困ったとき

- 「動いているので入れ替えません」: アプリの画面を「全て閉じる」で閉じる。コマンドからなら `sync down --all`。
- 「sha256 が一覧と違う」: ダウンロードした zip が壊れています。ダウンロードし直して `setup.cmd` をもう一度。
- コンポーネントが壊れたかもしれないとき: `setup.cmd -Full` で全ファイルを検証し直して、壊れたコンポーネントだけ再インストールします。

## Linux

1. Linux 用の配布物（`SyncStrata-<版>-linux.zip`）をダウンロードして展開し、端末で `./setup.sh` を実行します。足りないコンポーネントだけをインストールし、何度実行しても同じ結果になります。
2. アプリのメニュー（デスクトップにも置きます）の **Sync-Strata** から開きます。
3. コマンドは `sync.sh`（`./sync.sh up`・`./sync.sh down` など。中身は Windows の `sync` と同じ）。
4. アプリは `~/.local/share/SyncStrata` にインストールされ、設定と会話（`SYNC_HOME`）は `~/.config/SyncStrata` に保存されます。モデルの保存先は `settings.json` の `models_dir` です。
5. 更新・削除は、アプリのメニューの「Sync-Strata の更新」「Sync-Strata を消す」（`~/.local/share/SyncStrata/update.sh`・`uninstall.sh`）です。前のバージョンに戻すには、アプリのメニューの「Sync-Strata を前の版に戻す」（`~/.local/share/SyncStrata/rollback.sh`）を使います。
6. 要求スペック: 64 ビットの Linux（glibc 2.28 以降。作者の実機は Ubuntu 24.04 で、ほかのディストリビューションは未確認）、NVIDIA のドライバー R580 以上（Linux は 580.95.05 以上。GTX 10 系・V100・Titan V は 575.57.08 以上）。Radeon（RX 6000・7000・9000 系の単体の GPU。ノート用も）は HIP 版で、試験的な機能です（実機では未確認）。
7. 画面の無い PC（SSH でつなぐサーバーなど）は、アプリのメニューの代わりに `./sync.sh up --no-gui` で起動します。ウィンドウは開かず、エンジンと dsh だけを起動します。WSL2 と Mac は [README](../README.ja.md) の「対応する GPU」の下の注を読んでください。
