## 最終判定
- **最速構成は常用してよい。** 通算 約4.5時間の実負荷（第1回 約1.5時間 + 今回 約3時間）で、生成失敗・never rang・速度劣化・クラッシュのいずれも Sync 稼働中に発生していない。緩めるべき要素は今回も特定されなかった。
- 切り替え運用の前提は従来どおり: Sync 稼働中は 27B が止まる（機密ターン受け皿・記憶抽出も停止）。開始前に Windows Update の pending restart が無いことの確認は引き続き推奨する。
- 残る恒常リスクは母艦側のドライバ不安定性で、これは Sync の有無にかかわらず存在する（今朝の 0x139 BSOD が Sync 停止中に起きたことが証拠）。根本対策の候補は従来どおり ①AMD-RAID ドライバ（rcbottom.sys 9.3.3-00057）の更新 ②Sync モデル配置の C:（NVMe 直結）への移行 で、いずれもユーザー判断待ち。今朝の新規ダンプ（112126-8546-01.dmp）の解析も、必要なら別途判断されたい。
