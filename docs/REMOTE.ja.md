# スマホから使う

スマホのブラウザーから、PC で動いている Sync-Strata の会話の画面を使えます。スマホにアプリを入れる必要はありません。

## 同じ Wi-Fi のとき（QR）

1. **PC の画面**の設定で「スマホからの接続」を「同じ Wi-Fi」にします（この設定は PC の画面と CLI からだけ変えられます）。
2. 「今すぐ切り替える（dsh を再起動）」を押します。設定は dsh を起こし直したときに効きます（返答の途中なら止まります。エンジンは動いたままです）。
3. 出てきた QR を、同じ Wi-Fi につないだスマホのカメラで読み取ると、会話の画面が開きます。

QR は 3 分だけ・1 回だけ使える合い言葉です。長く使える鍵は PC の外に出ません。期限が切れたら「新しい QR」を押してください。

**同じ Wi-Fi の中では、通信は暗号化されません（http）。** 家など、信頼できる Wi-Fi で使ってください。

## 外出先から（Tailscale）

1. PC とスマホの両方に [Tailscale](https://tailscale.com/) を入れ、同じアカウントでログインします。
2. PC の画面の設定で「スマホからの接続」を「Tailscale」にして、「今すぐ切り替える」を押します。
3. 出てきた QR をスマホで読み取ります（スマホの Tailscale はオンにしておきます）。

Tailscale が通信を暗号化します。インターネットに直接ポートを開ける使い方は勧めません。

## CLI から

```
sync settings set lan_remote lan       # off・lan・tailscale
sync remote-apply                      # dsh と中継だけ起こし直して効かせる
sync remote-url                        # 今つなげる URL
sync remote-url --pair                 # GUI なしでスマホをつなぐ（3 分・1 回きりの URL と QR）
```

## つながらないとき

- 同じ Wi-Fi か（スマホがモバイル回線になっていないか）。
- Windows ファイアウォールで `dsh-node.exe`（Node.js）がプライベート ネットワークで許可されているか。
- PC の Wi-Fi のネットワークが「プライベート」になっているか（「パブリック」だとつながりません）。
- Tailscale のときは、PC とスマホの両方の Tailscale がオンでログインしているか。
- **PC のアドレスが変わったとき**（ルーターの再起動や別の Wi-Fi など）は、「今すぐ切り替える」か `sync remote-apply` で起こし直してから、新しい QR を読み取ってください。

## 注意

- スマホのログインは、QR を読んだ日から 30 日で切れます。残りが 7 日以内になると、スマホの画面と PC の『接続中の端末』に警告が出ます。期限を延ばすには PC の QR を読み直してください。万が一スマホを失くした場合は、PC の『接続中の端末』で取り消してください。取り消した端末はすぐに使えなくなります。
- 「オフ」にしても、dsh を起こし直すまではつながったままです。
- PC が休止すると、スマホからも使えなくなります。
